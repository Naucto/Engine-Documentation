=============
API Reference
=============

The Naucto Lua API provides a small, focused set of functions for building games. All functions are
available as globals in your Lua scripts.

Summary
=======

+----------------------------------------------+------------------------------------------+
| Function                                     | Description                              |
+==============================================+==========================================+
| :func:`clear`                                | Clear the screen with a palette color    |
+----------------------------------------------+------------------------------------------+
| :func:`sprite`                               | Draw a sprite or block of sprites        |
+----------------------------------------------+------------------------------------------+
| :func:`map`                                  | Draw the tilemap                         |
+----------------------------------------------+------------------------------------------+
| :func:`mget`                                 | Read a tile from the tilemap             |
+----------------------------------------------+------------------------------------------+
| :func:`fget`                                 | Read sprite flags                        |
+----------------------------------------------+------------------------------------------+
| :func:`camera`                               | Set the camera offset                    |
+----------------------------------------------+------------------------------------------+
| :func:`line`                                 | Draw a line                              |
+----------------------------------------------+------------------------------------------+
| :func:`rect`                                 | Draw an outlined rectangle               |
+----------------------------------------------+------------------------------------------+
| :func:`fill_rect`                            | Draw a filled rectangle                  |
+----------------------------------------------+------------------------------------------+
| :func:`key_pressed`                          | Check if a key is held down              |
+----------------------------------------------+------------------------------------------+
| :func:`print`                                | Write text to the output panel           |
+----------------------------------------------+------------------------------------------+
| :func:`set_col`                              | Remap a palette color                    |
+----------------------------------------------+------------------------------------------+
| :func:`reset_col`                            | Restore the original palette             |
+----------------------------------------------+------------------------------------------+
| :func:`play_music`                           | Play a Sound Editor music slot           |
+----------------------------------------------+------------------------------------------+
| :func:`stop_music`                           | Stop music playback                      |
+----------------------------------------------+------------------------------------------+
| :func:`net.host`                             | Host an online multiplayer session       |
+----------------------------------------------+------------------------------------------+
| :func:`net.join`                             | Join an online multiplayer session       |
+----------------------------------------------+------------------------------------------+
| :func:`net.leave`                            | Leave the current session                |
+----------------------------------------------+------------------------------------------+
| :func:`net.id`                               | Your player id in the session            |
+----------------------------------------------+------------------------------------------+
| :data:`net.state`                            | Table shared by all players              |
+----------------------------------------------+------------------------------------------+
| :func:`net.emit`                             | Send a custom event to the other players |
+----------------------------------------------+------------------------------------------+
| :func:`net.on`                               | React to network events and changes      |
+----------------------------------------------+------------------------------------------+
| :func:`net.lock`                             | Mutual exclusion between players         |
+----------------------------------------------+------------------------------------------+
| :func:`net.queue`                            | Shared first-in, first-out queue         |
+----------------------------------------------+------------------------------------------+
